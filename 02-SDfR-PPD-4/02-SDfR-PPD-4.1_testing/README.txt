In order to compile, main.cpp, OvernightPackage.cpp, Package.cpp and TwoDayPackage.cpp as well as the header files Package.h, OvernightPackage.h and TwoDayPackage.h must be included. 
Typing the following in the command line will successfully include and compile all of the needed files: 

g++ -Iinclude src/*.cpp -o assignment


After compiling is successful typing the following will run the program:

.\assignment
